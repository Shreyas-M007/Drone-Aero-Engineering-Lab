Prerequisites & Setup\n\nCapacitor wraps the web workspace inside a native OS shell, loading web resources inside high-speed WebGL WebViews while exposing native camera interfaces for the AR scanner.\n\nEnsure you have the following installed on your machine:\n- [Node.js](https://nodejs.org/) (LTS version)\n- **Android Studio** (for compiling Android APKs/Bundle AABs)\n- **Xcode** (for compiling iOS App Store builds - requires macOS)\n\n### Initializing Capacitor\n\nOpen your terminal in the [DroneIdeaLabScratch](file:///C:/Users/shrey/.gemini/antigravity/scratch/DroneIdeaLabScratch) folder and run:\n\n```bash\n# 1. Initialize the project configuration\nnpx cap init \"Drone Aero Lab\" \"com.droneaerolab.app\" --web-dir=.\n```\n\nThis creates a `capacitor.config.json` file in the workspace directory.
